## 핵심 결과

- 명절 연휴는 평소 평일의 2.5배, 무료개방일은 1.4배를 배치하고, 황금연휴엔 궁·종묘에 2명을 더한다.
- 최종 모델: Chronos-2 제로샷 + 공휴일 묶음 + 공식 무료개방 표시, 인력 = 0.8 분위수 ÷ 2,000명.
- 2025 백테스트(27개 원점 × 23개소, 7,204 개소·일): WAPE 46.3% → 29.3%, 인력 비용 15.66억 → 8.58억 원(7.08억 절감 = 서비스 수준 보정 2.34억 + 모델 4.74억). 근무표는 2주 치를 확정한다.
